# Трекер привычек — приложение для компьютера (Windows) и iPhone

Тот же трекер, что и в Claude (артефакт «Трекер привычек»), но работает на вашем компьютере без интернета:
привычки по времени суток, серии 🔥, баллы и медали, статистика, архив и **таблетки с будильником**.
Данные хранятся у вас на компьютере в файле, с телефона и компьютера видны одни и те же отметки.

## Установка (Windows)

1. Откройте вкладку **Actions** репозитория → последняя успешная сборка «Сборка HabitTracker» → блок **Artifacts**.
2. Скачайте **HabitTracker-Setup**, распакуйте и запустите `HabitTracker-Setup.exe`.
   Права администратора не нужны: программа ставится в профиль пользователя.
   Если Windows SmartScreen покажет «Защитник Windows предотвратил запуск», нажмите **Подробнее → Выполнить в любом случае**
   (у программы нет платной цифровой подписи).
3. В меню «Пуск» и на рабочем столе появится **Трекер привычек**.

Без установки: скачайте **HabitTracker-portable** и запустите `HabitTracker.exe`, данные будут храниться в папке `habit_data` рядом с ним.

Трекер открывается отдельным окном (через Microsoft Edge в режиме приложения). Чёрное окно консоли — это сервер трекера,
его не закрывайте, пока пользуетесь трекером (можно свернуть).

Удаление: «Пуск» → Трекер привычек → **Удалить Трекер привычек**, или «Параметры → Приложения». Ваши отметки при удалении сохраняются.

## Что умеет

| Вкладка | Что там |
|---|---|
| **Сегодня** | привычки, сгруппированные по утру, дню и вечеру; отметка одним нажатием, серия 🔥, полоска последних 7 дней; меню «⋯» — в архив или удалить |
| **Таблетки** | расписание приёма на сегодня, кнопка «Принять», пропущенные приёмы; будильник со звуком в назначенное время, «Через 10 мин», «Принял(а)» |
| **Медали** | баллы (1 день с выполненной привычкой = 1 балл) и медали от 1 до 1000 дней |
| **Статистика** | средний уровень, лучшая серия, календарь активности за 17 недель, каждая привычка за 30 дней |
| **Архив** | привычки на паузе — вернуть или удалить |

Привычки: ежедневно, по дням недели или X раз в неделю; категория и время суток. Тема — авто, светлая или тёмная (кнопка вверху).

Будильник звонит, пока трекер открыт (окно может быть свёрнуто). Если в минуту приёма компьютер «спал»
или окно было скрыто, будильник сработает, как только трекер снова окажется на экране (в течение 30 минут после времени приёма).
Если звука нет — нажмите «Проверить звук» на вкладке «Таблетки».

## На iPhone (через компьютер в той же Wi-Fi сети)

1. На компьютере: «Пуск» → **Трекер привычек для iPhone (Wi-Fi)** (или `Запуск для iPhone.bat` рядом с переносным exe).
   Если Windows спросит про брандмауэр — разрешите доступ в **частных** сетях.
2. В окне появится адрес вида `http://192.168.1.5:8770/` — откройте его в Safari на iPhone.
3. «Поделиться» → **«На экран «Домой»»**. Трекер откроется со своего значка на весь экран.

Отметки с телефона и с компьютера попадают в один файл: если отметить что-то одновременно на двух устройствах,
изменения объединятся. Компьютер с трекером должен быть включён. Используйте только домашнюю Wi-Fi сеть: пароля у трекера нет.
При установке можно включить «Запускать вместе с Windows» — тогда трекер будет доступен с телефона сразу после включения компьютера.

## Где хранятся данные

- установленная версия: `%LOCALAPPDATA%\HabitTracker\habits.json`
- переносная версия: `habit_data\habits.json` рядом с exe

Раз в день в папку `backups` рядом с ним кладётся резервная копия (хранятся последние 30).
Перенести данные на другой компьютер: скопируйте файл `habits.json` в ту же папку на новом компьютере.
Данные из первой версии приложения переносятся автоматически.

## Запуск через Python (любая система)

Нужен только Python 3.10+, сторонние библиотеки не требуются.

```
python habit_app.py              # отдельное окно (Edge) или браузер
python habit_app.py --browser    # во вкладке браузера
python habit_app.py --lan        # открыть с телефона в той же Wi-Fi сети
python habit_app.py --port 9000  # другой порт (по умолчанию 8770)
```


## Сборка самостоятельно

Страница трекера — это артефакт из Claude: исходник `web/src/habit-tracker.html`.
`web/build.mjs` собирает из него `app/index.html` без внешних библиотек: JSX → JavaScript (esbuild с React внутри),
классы Tailwind → готовый CSS. Нужен Node.js: `cd web && npm ci && node build.mjs`.
Тот же исходник можно опубликовать артефактом в Claude — там данные хранятся в браузере.

`build_exe.bat` собирает страницу (если есть Node.js), `dist\HabitTracker.exe` (PyInstaller) и, если установлен
[Inno Setup 6](https://jrsoftware.org/isdl.php), установщик `dist\HabitTracker-Setup.exe`.

Автоматическая сборка GitHub Actions (`.github/workflows/build-exe.yml`) на Windows собирает страницу и exe,
проверяет трекер в Edge (`tools/check_app.py`: отметки, медали, меню, лекарства и будильник — в том числе когда
вкладка «спала» в минуту приёма, «Через 10 мин», одновременные изменения с компьютера и телефона), собирает установщик
и проверяет установку, запуск и удаление. При пуше тега `v*` установщик и exe публикуются во вкладке **Releases**.
