# Трекер привычек — приложение для компьютера (Windows) и iPhone

Отмечайте каждый день, что сделали. Трекер считает серии 🔥, показывает прогресс за день, неделю и по месяцам.
Работает без интернета, данные хранятся у вас на компьютере.

## Установка (Windows)

1. Откройте вкладку **Actions** репозитория → последняя успешная сборка «Сборка HabitTracker» → блок **Artifacts**.
2. Скачайте **HabitTracker-Setup**, распакуйте и запустите `HabitTracker-Setup.exe`.
   Права администратора не нужны: программа ставится в профиль пользователя.
   Если Windows SmartScreen покажет «Защитник Windows предотвратил запуск», нажмите **Подробнее → Выполнить в любом случае**
   (у программы нет платной цифровой подписи).
3. В меню «Пуск» и на рабочем столе появится **Трекер привычек**.

Без установки: скачайте **HabitTracker-portable** и запустите `HabitTracker.exe`, данные будут храниться в папке `habit_data` рядом с ним.

Трекер открывается отдельным окном (через Microsoft Edge в режиме приложения). Чёрное окно консоли — это сервер трекера,
его не закрывайте, пока пользуетесь трекером (можно свернуть).

Удаление: «Пуск» → Трекер привычек → **Удалить Трекер привычек**, или «Параметры → Приложения». Ваши отметки при удалении сохраняются.

## Что умеет

| Вкладка | Что там |
|---|---|
| **Сегодня** | привычки на день, кнопка-отметка, счётчик для привычек «сколько раз» (8 стаканов воды, 20 минут чтения), прогресс дня; стрелками можно отметить прошлые дни |
| **Неделя** | таблица привычек × дни недели, отметка нажатием на клетку, процент выполнения по дням |
| **Статистика** | выполнение за 30 дней, идеальные дни, текущая и лучшая серия, календарь-тепловая карта по каждой привычке |
| **Привычки** | добавить, изменить (название, значок, цвет, дни недели, количество в день, дата начала), порядок, архив, удаление; светлая и тёмная тема; сохранение в файл и загрузка из файла |

Серия считается только по дням из расписания: если привычка «по будням», выходные серию не прерывают.
Сегодняшний день серию не прерывает, пока он не закончился.

## На iPhone (через компьютер в той же Wi-Fi сети)

1. На компьютере: «Пуск» → **Трекер привычек для iPhone (Wi-Fi)** (или `Запуск для iPhone.bat` рядом с переносным exe).
   Если Windows спросит про брандмауэр — разрешите доступ в **частных** сетях.
2. В окне появится адрес вида `http://192.168.1.5:8770/` — откройте его в Safari на iPhone.
3. «Поделиться» → **«На экран «Домой»»**. Трекер откроется со своего значка на весь экран.

Отметки с телефона и с компьютера попадают в один файл: если отметить что-то одновременно на двух устройствах,
изменения объединятся. Компьютер с трекером должен быть включён. Используйте только домашнюю Wi-Fi сеть: пароля у трекера нет.
При установке можно включить «Запускать вместе с Windows» — тогда трекер будет доступен с телефона сразу после включения компьютера.

## Где хранятся данные

- установленная версия: `%LOCALAPPDATA%\HabitTracker\habits.json`
- переносная версия: `habit_data\habits.json` рядом с exe

Раз в день в папку `backups` рядом с ним кладётся резервная копия (хранятся последние 30).
Перенести данные на другой компьютер: «Привычки» → **Сохранить в файл**, на новом компьютере — **Загрузить из файла**.

## Запуск через Python (любая система)

Нужен только Python 3.10+, сторонние библиотеки не требуются.

```
python habit_app.py              # отдельное окно (Edge) или браузер
python habit_app.py --browser    # во вкладке браузера
python habit_app.py --lan        # открыть с телефона в той же Wi-Fi сети
python habit_app.py --port 9000  # другой порт (по умолчанию 8770)
```

`app/index.html` можно открыть и просто как файл в браузере, тогда данные хранятся в самом браузере.

## Сборка самостоятельно

`build_exe.bat` собирает `dist\HabitTracker.exe` (PyInstaller) и, если установлен [Inno Setup 6](https://jrsoftware.org/isdl.php),
установщик `dist\HabitTracker-Setup.exe`.

Автоматическая сборка GitHub Actions (`.github/workflows/build-exe.yml`) на Windows:
собирает exe, проверяет интерфейс в Edge (`tools/check_app.py`: добавление привычек, отметки, серия,
одновременные изменения с двух устройств), собирает установщик, проверяет установку, запуск и удаление.
При пуше тега `v*` (например `v1.0.0`) установщик и exe публикуются во вкладке **Releases**.
