# Публикация «Привычек» в Google Play

Всё, что нужно заполнить в [Play Console](https://play.google.com/console), — по порядку.
Картинки лежат в `store/google-play/`, пересоздать их: `python store/make_store_assets.py`.

## 1. Что нужно заранее

- **Аккаунт разработчика Google Play** — разовый взнос 25 $, подтверждение личности.
- **Постоянный ключ подписи** в секретах репозитория (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`).
  Без него сборка не создаёт AAB. Этот ключ — *ключ загрузки*: Google Play сам переподписывает приложение
  своим ключом (Play App Signing). Если ключ загрузки потеряется, его можно сменить через поддержку Google.
- **Файл для загрузки** — `Privychki.aab` из сборки «Сборка Android (APK)» → Artifacts → **Privychki-google-play**.

## 3. Содержание приложения (App content)

**Безопасность данных (Data safety):**
- Собирает ли приложение или передаёт какие-либо типы данных пользователей? — **Нет.**
  (Данные хранятся только на устройстве и никуда не отправляются — Google не считает это «сбором».)
- Шифрование при передаче — не применимо (ничего не передаётся).
- Удаление данных — удалением приложения или в самом приложении.

**Реклама:** нет. **Доступ к приложению:** все функции доступны без входа.
**Целевая аудитория:** 18+ (из-за напоминаний о лекарствах не выбирайте детские возрастные группы).
**Возрастной рейтинг (анкета IARC):** категория «Утилиты/продуктивность»; на все вопросы о насилии, азартных играх,
общении пользователей, покупках — «Нет».
**Приложения о здоровье (Health apps declaration):** отметьте «Управление лекарствами / напоминания о приёме»
и что приложение **не является медицинским изделием**.
**Точные будильники:** приложение использует `SCHEDULE_EXACT_ALARM` (пользователь разрешает сам в настройках
«Будильники и напоминания»), поэтому отдельная декларация для `USE_EXACT_ALARM` не нужна.

## 4. Тестирование и выпуск

Для **новых личных аккаунтов** Google требует закрытое тестирование: не меньше **12 тестировщиков в течение 14 дней**,
и только после этого открывается публикация для всех. Порядок:

1. «Тестирование → Закрытое тестирование» → создать трек, загрузить `Privychki.aab`, добавить тестировщиков (их Gmail).
2. Через 14 дней — «Продакшен» → создать выпуск из той же сборки → отправить на проверку (обычно от нескольких часов до 7 дней).

Каждая новая версия: GitHub Actions сам увеличивает номер версии; загрузите новый `Privychki.aab` в нужный трек.
